# 🐍 Python Algorithms & OOP Exercises

This repository contains a collection of programming challenges ranging from basic mathematical logic to advanced data structures and Object-Oriented Programming (OOP).

## 🚀 Repository Content

The exercises are organized by complexity level:

### 🟢 Beginner & Intermediate Levels
*   **Fibonacci Sequence:** Calculating the sequence using efficient iteration.
*   **Square Root (Bisection):** Implementation of the numerical method to find roots with custom precision.
*   **Credit Card Validator:** Implementation of the [Luhn Algorithm](https://wikipedia.org) to validate credit card numbers.
*   **Towers of Hanoi:** Solving the classic puzzle using recursion.

### 🟡 Object-Oriented Programming (OOP)
*   **Shape Calculator:** Demonstration of **inheritance** and polymorphism between Rectangles and Squares.
*   **Budget App:** Management of deposits, withdrawals, and transfers with terminal-based spending charts.
*   **Character System:** Use of **@property and setters** for encapsulation of health, mana, and level.
*   **Player Movement:** Implementation of **Abstract Base Classes (ABC)** to define movement behaviors.

### 🔴 Advanced Data Structures
*   **Adjacency Matrix:** Converter for graphs represented as adjacency lists into matrices.
*   **Hash Table:** Manual implementation of a hash table with collision handling.

## 🛠️ How to Run the Exercises

All scripts are ready to be executed directly from your terminal.
* Run any file using Python 3
